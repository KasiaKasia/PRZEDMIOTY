Formularze sterowane szablonem

[(ngModel)] musi zawierać właściwość name w tgach HTML takich jak input , textarea, select itp aby można było powiązać je z formularzem .

Jak brakuje pojawia sie komunikat błędu

ERROR RuntimeError: NG01352: If ngModel is used within a form tag, either the name attribute must be set or the form control must be defined as 'standalone' in ngModelOptions.

Example 1: <input [(ngModel)]="person.firstName" name="first">

Example 2: <input [(ngModel)]="person.firstName" [ngModelOptions]="{standalone: true}">

Dla radio trzeba pamietać aby wartość value zawsze była inna , poniewaz nie będą się przełaczać poprawnie.

Aby wstawić w radio wartości true i false trzeba zastosować wiązanie [value]="true"

Dla checkbox wartość true lub false jest brana od razu

Aby uzyskać dostęp do formularza sterowanego szablonem wystarczy zastosować pojedyńcze wiązanie [ngModel].

W tym przypadku po kliknieciu dopiero w przycisk będą widoczne zmiany w ngForm?.value .

W dla obiektu formData nie będą dostępne w przypaku pojedyńczego wiązania [ngModel]

Za pomocą derektywy @ViewChild(NgForm) formDirective!: NgForm; may dostęp do formularza ngForm
